現場で試す4つの施策

毎月の主KPIは定期顧客の純増（当月末の継続人数 − 前月末の継続人数）。施策ごとのKPIで、次に手を入れる場所を判断する。

POPUP接客マニュアル

現場報告　単品購入2件・定期購入0件。接客人数と集計期間は未確認。

  1. 使い方を聞く。 夜のお手入れの流れを聞き、テスターがあれば美容水から美乳液を重ねる順番で試してもらう。
  2. 購入方法を比べる。 会場・ECの表示を確認して、通常・定期の総額、次回価格、送料、周期、変更・解約方法を同じ順番で伝える。
  3. 次の行動を案内する。 購入希望には会場用フォーム。後で検討したい人には、希望に応じて使い方や購入条件を見られるLINE・QRを案内。
「まず一度使ってみたいですか。それとも、合いそうなら定期も検討したいですか。通常と定期の条件をここで比べられます。」

KPI　会場経由の定期初回決済。接客数・比較案内数・単品購入数・LINE追加も残す。

KDI　次回出店で台本を使い、閉店後に件数と実際に聞いた見送り理由を集計する。

購入後LINEと既存顧客の継続

購入完了画面や会場で公式LINEを案内。最初は「登録直後＋使用開始後の1通」を試す。

  1. 登録直後　2ステップの順番と使用量、よくある質問を案内する。
  2. 使用開始から約1週間・単品購入者　使い方の補足と、続けたい人向けに通常・定期の比較を案内する。
  3. 使用開始から約1週間・定期購入者　次回のお届けの確認先とFAQを案内する。購入種別・日付が分かる範囲で分けて配信する。

注文メールと重なる内容を確認し、配信数・クリック・ブロックを見て頻度を調整する。次回予定を知らせる場合は、変更期限と実際のお届け予定日に合わせる。

KPI　購入者LINE追加数、単品から定期への初回決済、2回目決済の人数と率、解約・休止人数。

KDI　既存配信を確認して単品・定期向けの文面を作り、週1回結果を確認する。

少ない流入から定期を獲得する

通常・定期の比較をECトップに1ブロック置く。初回と次回以降の価格・送料・周期・変更条件をそろえ、商品ページの使い方と保証への導線を確認する。

KPI　商品ページ到達数、定期購入ボタンのクリック数、初回決済人数。

KDI　購入ガイド1ブロックを試し、スマホで購入までの導線と計測を点検。少ない件数は実数と率を併記する。

追加広告費をかけずに流入を増やす

既存POPUPのQRと自社Instagramから始め、過去PRで反応があった訴求を再活用する。流入元ごとにリンクを分け、同じ商品ページで比較する。

KPI　POPUP・Instagram・PR別の商品ページ到達と定期初回決済。

KDI　既存素材で週1本、過去PRを1件ずつ確認。会場の質問をFAQに反映して検索からの入口にもする。

POPUPで知ってLINEから購入した場合は、最初の接点と購入直前の経路を記録し、注文は1件として集計する。

Amazon・Qoo10

  1. Amazonの商品ページで夜の2ステップが伝われば、購入が増える。

    既存画像1枚で「何が届くか・使う順番」を見せ、レビューの整理で挙がった使用感と手軽さを訴求候補にする。見る数字はセッション、注文点数、ユニットセッション率。

  2. 検索される用途に商品情報を合わせると、Amazonで見つけてもらいやすい。

    既存のタイトルと商品属性で、ナイトケア・美容水・乳液の情報を確認して1か所改善。広告を増やさずセッションの推移を見る。

  3. Qoo10のセット内容と配送条件が分かりやすければ、通常購入につながる。

    出品済みの1商品で画像・説明・到着目安を点検。閲覧、注文と手数料等を差し引いた残りを確認する。

  4. 使用感を試せるQoo10の体験企画なら、初見でも商品の価値を理解しやすい。

    参加枠、費用、最低サンプル数を先に確認し、条件が合う場合に企画を検討。体験後の商品ページ到達と購入を測る。Qoo10の体験企画

POPUP

  1. 接客で通常と定期を同時に比べられれば、定期を選ぶ人が出る。

    次の出店で比較台本を使う。案内人数、単品・定期の決済、見送り理由を数える。

  2. 美容水と美乳液を順番に体験すると、2本を使う理由が伝わりやすい。

    既存のテスターで2ステップを案内。体験数、仕上がりを好んだ人、購入まで進んだ数を見る。

  3. 会場で決めなかった人も、帰宅後に条件を確認できれば購入候補になる。

    希望者に会場別QRを案内。QRからのアクセス、LINE追加、後日の初回決済を追う。

購入後LINE・継続

  1. 購入直後に使い方を受け取れると、購入者がLINEを追加しやすい。

    購入完了画面または会場の案内を1か所見直す。購入数に対するLINE追加数と使い方リンクのクリックを確認する。

  2. 使い始めた後に定期の条件を見られれば、単品購入から定期に進みやすい。

    単品購入者向けの案内を1通用意し、比較ページの到達と初回定期決済を追う。

  3. 使い方や次回確認先が分かれば、定期2回目の前に困りごとを解消できる。

    定期購入者向けにFAQと次回確認先を案内。2回目決済の人数と率、問い合わせ・休止理由を確認する。

  4. 注文メールとの重複を減らすと、必要なLINEが読まれやすい。

    現在の配信とメールを一覧で比較。重複する案内を1件減らした場合のクリック・ブロック数を確認する。

自社EC

  1. 通常・定期の総額と周期を最初に比べられれば、購入を判断しやすくなる。

    ECトップに比較ブロックを追加する案を試す。商品リンクのクリックと定期初回決済を見る。

  2. 商品ページの上部で夜の使い方が分かれば、商品価値を伝えやすい。

    既存写真で使う順番を1ブロックにする。商品到達後の定期ボタンクリックを比較する。

  3. 保証の条件と負担が購入前に見えれば、迷いが減る。

    購入ボタン近くの保証リンクと説明を見直す。保証に関する質問と購入後の返金数を追う。

  4. スマホで定期ボタンの位置が分かりやすければ、購入画面に進む人が増える。

    実機で商品ページから購入画面までを点検する。ボタン押下と注文開始の差を確認する。

広告以外の集客と販売

  1. Instagramで使用場面を見せると、商品ページへの流入が増える。

    既存画像で「2本を組み合わせる理由」と「夜の2ステップ」を順に試す。投稿別リンクの到達を比較する。

  2. 過去PRで購入に近かった訴求を再利用すると、投稿の成果を改善できる。

    もちゃころなど既存のPRを再生・アクセス・購入まで振り返る。自社素材で再現した投稿の到達と初回決済を測る。

  3. 会場で多い質問を公開FAQにすると、検索から商品にたどり着く入口になる。

    使う順番・周期など実際の質問から1本公開する案。検索表示、クリック、FAQから商品ページへの遷移を追う。

  4. TikTok Shopの既存クリエイター経由で利益が残るなら、追加広告を使わず売上を増やせる。

    過去のTAP実績を、注文・手数料・報酬・返品・配送込みで見直す。採算が確認できた施策を継続候補にする。

  5. 過去に接点のあった温浴・サロン施設なら、新規の卸開拓より小さく試せる。

    過去の反応がよかった接点を1件選び、少量テストの条件を試算する。卸売上、利益、準備工数、再発注で判断する。
